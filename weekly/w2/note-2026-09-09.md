## CRS transform
the PROJ library should be able to take any coordinate in one CRS and transform it to another. Appears to be working with all EPSG formats.

*Netherlands*
NAP height --> EVRF2019 height --> Determined at 1095 points, SD 0.008m. Offset: mean 0.021m, minimum 0.009m, maximum 0.055m
RD New + NAP height  --> WGS84 --> 1m accuracy transform

*Germany*
DHHN2016 height (German height) --> EVRF2019 height (European height) --> Determined at 802 points, SD 0.010m. Offset: mean 0.013m, minimum -0.008m, maximum 0.039m. 
UTM zone 32N (Germany) --> WGS84 --> 1m accuracy transform

*Belgium*
no height datum for belgium available
Belgium Lambert72 --> WGS84 --> 1m accuracy transform

*France*
NGF-IGN69 height --> EVRF2019 --> Determined at 1228 points, SD 0.054m. Offset: mean -0.539m, minimum -0.651m, maximum -0.380m
Lambert-93 -- France --> WGS84 --> 1m accuracy transform

*Swiss*

LV95 -- Swiss CH1903+ --> WGS84 --> 1m accuracy

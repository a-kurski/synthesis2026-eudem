This project is a joint effort by Rijkswaterstaat, Deltares, and TU Delft. The main aim is the creation of a pipeline to create a harmonized cross-border digital elevation model (DEM) of the Rhine catchment area, which is home to ca. 60 million people. With recent droughts and increased flooding risk, being able to predict the flow of water is highly relevant for batter water management. The catchment area covers several European countries — each of them collects and processes elevation data following INSPIRE directive, but the actual methodology differs. These differences include how the elevation is measured, bodies of water are represented, map projections, accuracy of measurements and their resolution. The outcome of the project will be a harmonised elevation map of the Rhine area assembled from heterogenous point clouds, and a harmonisation pipeline which can be expanded to the pan-European scale.
